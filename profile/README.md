# TransMac — HFS tree on a Windows desk you own

TransMac holds a Windows desk for HFS volumes on media you own: the Mac disk tree, the owned media, and a short note the next operator can read. Extra disks wait for their own title.

## Session Card

| Slice | What you do in TransMac | What remains |
|-------|------------------------|--------------|
| Arrival | Open TransMac and name today's Windows desk | A titled HFS tree |
| Focus | Keep only live volumes on the TransMac board | A short Mac-disk list |
| Check | Read TransMac HFS volumes before a large copy | A confirmed Windows desk |
| Handoff | Mark finished volumes inside TransMac | A note for the next operator |

## How TransMac Sits

TransMac does not replace a mix of other people's disks, an HFS tree on media you do not own, or a Mac volume that is not yours. It sits beside them as a named Windows desk for one job: which HFS volumes are live, which Mac disk still matches owned media, and what the next operator should read.

Each operator on a shared PC keeps a TransMac style of their own. Extra disks wait for their own title instead of crowding the live tree.

A first visit should be one short HFS pass on media you brought, then the same TransMac Windows desk the next day. That is enough to see if the named tree holds.

## Traffic Light

| Signal | On the TransMac board | What you do |
|--------|----------------------|-------------|
| Green | Named HFS tree, short live Mac-disk list | Continue the same owned media |
| Amber | Two disks mixed on one Windows desk | Split the tree before a large change |
| Red | No title, no note, a mix of disks you do not own | Stop and name the Windows desk first |
| Clear | Handoff written, live volumes few | Close TransMac and leave the Windows desk |

## Open Order

1. Open the last TransMac Windows desk, not a new empty HFS tree.
2. Confirm the Mac disk is media you own, then read the tree and the last handoff.
3. Finish one visible HFS pass inside TransMac on a volume you brought.
4. Write what changed, then close with fewer mixed disks than you found.
5. If the tree feels crowded, drop anything that belongs to a different TransMac job.

## After a Week

A week in TransMac is not a larger mix of other people's disks. It is the same title, a shorter live Mac-disk list, and a note that still makes sense before the next HFS tree.

Leave TransMac with a quieter Windows desk than the one you opened. The next visit should start on that named HFS tree, not on media you do not own.

## Sign-off

- [ ] The TransMac workspace name is short enough to scan
- [ ] Only media you own sit on the HFS volumes
- [ ] A second operator can read the tree handoff
- [ ] The last TransMac Mac disk still opens after a restart
- [ ] Finished volumes are off the live TransMac set

## Field Note

TransMac is easier to trust when the Windows desk stays on HFS you own. Name the tree, keep the live Mac disk, finish one visible pass, and write what changed.

The same loop fits a shop file, a close-out, or a shared PC. Open the last TransMac desk and continue. Do not open Mac volumes you are not authorized to read.
